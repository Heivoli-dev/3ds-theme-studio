Installer avec Anemone3DS

  1. Connectez la 3DS au même Wi-Fi que cet ordinateur.
  2. Lancez Anemone3DS, appuyez sur R pour ouvrir le lecteur QR.
  3. Visez ce code : le thème se télécharge et s'ajoute à la liste.
  4. Sélectionnez-le puis appuyez sur A pour l'appliquer.
Serveur local actif — gardez cette fenêtre ouverte.

Si rien ne se passe : autorisez « 3DS Theme Studio » dans le pare-feu (Windows le demande au premier lancement).
